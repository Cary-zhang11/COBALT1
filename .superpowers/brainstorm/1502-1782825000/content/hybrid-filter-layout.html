筛选逻辑总结

区域 筛选方式 可选范围 说明
6 个 KPI 卡片 🔗 统一筛选 本周 / 本月 / 近30天 一个切换全局生效，保证核心指标在同一时间基线
趋势图 🔓 独立筛选 近7天 / 近30天 / 近90天 可单独拉长时间看趋势，不强制与 KPI 卡片同步
饼图 / 分布图 🔓 独立筛选 近7天 / 近30天 各图表右上角有下拉框，自由切换

优点

  • KPI 卡片保持同一时间基线，避免对比混乱
  • 图表可独立探索更大时间范围，灵活性强
  • 筛选器不冗余 — KPI 区只有 1 个，图表区按需各自 1 个
  • 后端 API 按区域分别传参，实现清晰

注意事项

  • KPI 和图表时间范围可能不一致，需在 UI 上明确标注当前时间窗口
  • 后端需支持各端点独立接收 timeRange 参数
