时间筛选方案对比

每个 KPI 参数增加时间范围筛选 — 整体全局筛选 vs 各数据独立筛选

A

方案 A：顶部全局时间筛选器

在 KPI 卡片区域上方放一个统一的时间范围选择器（如"近 7 天 / 近 30 天 / 近 90 天"），所有卡片和图表统一切换。

B

方案 B：每个 KPI 卡片独立筛选

每个 KPI 指标卡片右上角各有一个小时间选择器，各数据独立设置时间范围，灵活但复杂。

我的推荐

推荐方案 A（全局时间筛选），理由如下：
  • 数据看板的核心价值是同一时间窗口下的全局视图，各指标混用不同时间范围反而引起混淆
  • 方案 B 在每个卡片上都放筛选器，会产生大量重复 UI 元素，视觉嘈杂
  • 方案 A 更简洁，一次切换即可全局刷新，操作效率更高
  • 统计 API 也只需传一个时间参数，后端实现更简单
