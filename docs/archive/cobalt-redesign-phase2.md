# COBALT Phase 2 交互重构方案

## 一、改动范围

| 改动项 | 说明 |
|--------|------|
| 取消左右气泡 | 所有消息统一上下堆叠，不再有 `.message.user` 右对齐和 `.message.ai` 左对齐 |
| 输入区上方快捷方案 | 主视图底部（输入框上方）常驻一排"常用方案"卡片，点击直接带入流程 |
| 侧边栏简化 | 移除独立的"Skill 市场"导航项，功能收敛到主界面 |
| 消息卡片统一 | 用户输入和 AI 回复都用同一种卡片样式，仅通过前缀标签区分角色 |
| 流程感强化 | Stepper 常驻在流程卡片顶部，随时可见当前阶段 |

## 三、流程卡片流（核心改动）

### 3.1 消息卡片统一样式

所有消息不再分左右，统一为 **居中卡片流**（宽度 100%，最大 720px，居中）：

```
┌────────────────────────────────────────────┐
│ 用户                                       │  ← 左上角小标签
│ 请帮我生成用户中心的测试用例                │
└────────────────────────────────────────────┘
              ↓
┌────────────────────────────────────────────┐
│ AI                                         │  ← 左上角小标签
│ 已分析您的需求，为您推荐以下常用方案：       │
│                                            │
│  [📋 测试用例生成] [📐 测试计划] [✅ QA]   │
└────────────────────────────────────────────┘
              ↓
┌────────────────────────────────────────────┐
│ 用户                                       │
│ 选择了：测试用例生成                        │
└────────────────────────────────────────────┘
              ↓
┌────────────────────────────────────────────┐
│ AI                                         │
│ [Stepper: 解析✓ → 分析✓ → 匹配✓ → 确认●]  │
│                                            │
│ 工作流已启动 — 测试用例生成 v1.2.0         │
└────────────────────────────────────────────┘
              ↓
┌────────────────────────────────────────────┐
│ 用户                                       │
│ 全部功能模块                                │
└────────────────────────────────────────────┘
              ↓
┌────────────────────────────────────────────┐
│ AI                                         │
│ [Stepper: ... → 生成● → 审核○]             │
│                                            │
│ 产出已生成，请审核：                        │
│ ┌──────────────────────────────────────┐   │
│ │ # 测试用例文档                        │   │
│ │ ...                                  │   │
│ └──────────────────────────────────────┘   │
│ [下载] [复制]                              │
└────────────────────────────────────────────┘
```

### 3.2 卡片样式规范

| 元素 | 样式 |
|------|------|
| 卡片容器 | `max-width: 720px; margin: 0 auto;` 居中，无边框或 1px `#E2E8F0` 边框 |
| 角色标签 | 左上角小标签，用户=灰色 `#94A3B8`，AI=蓝色 `#2563EB` |
| 卡片背景 | 全部白色 `#FFFFFF`，仅 Stepper 内部用 `#F1F5F9` |
| 卡片间距 | 每条消息之间 16px |
| 卡片内边距 | 16px |
| 卡片圆角 | 12px |

### 3.3 Stepper 展示规则

- Stepper 不再嵌入在 AI 消息气泡内，而是**独立成卡**或**紧跟在 AI 消息卡片顶部**
- 当工作流状态为 `running` 或 `paused` 时，Stepper 在最新 AI 消息上方固定展示
- 已完成的工作流，Stepper 折叠为一条紧凑型进度条

## 四、常用方案快捷卡片（输入区上方）

### 4.1 位置

在 `chatArea` 底部、`input-row` 上方，作为常驻快捷入口：

```
┌────────────────────────────────────────────────────┐
│                                                    │
│  [流程卡片流 ...]                                  │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │ 💡 常用方案                                   │  │
│  │ ┌──────────┐ ┌──────────┐ ┌──────────┐      │  │
│  │ │ 📋 测试  │ │ 📐 计划  │ │ ✅ QA    │ ...  │  │
│  │ └──────────┘ └──────────┘ └──────────┘      │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│  [输入框]                              [附件][发送]│
└────────────────────────────────────────────────────┘
```

### 4.2 样式

- 区域标题 "常用方案"，小字灰色
- 卡片横向排列，可横向滚动（如果数量多）
- 每个卡片：图标 + 名称，小尺寸（compact）
- 点击后直接启动对应 Skill 的流程（等同于旧版的 `startNewProjectWithSkill`）
- 当有正在运行的流程时，该区域可折叠为单行标签组

### 4.3 Skill 映射

| 图标 | 名称 | 触发 Skill |
|------|------|-----------|
| ClipboardList | 测试用例 | test-cases |
| Ruler | 测试计划 | test-plan |
| CheckCircle2 | QA 清单 | qa-checklist |
| Code | 测试代码 | test-code |

## 七、实施计划

按以下顺序修改 `cobalt.html`：

1. **CSS**：删除 `.message.user` 右对齐样式，改为统一居中卡片
2. **CSS**：新增 `.flow-card` 统一卡片样式，带角色标签
3. **CSS**：新增 `.quick-skills` 输入区上方快捷方案区域
4. **HTML**：侧边栏移除 "Skill 市场" 导航项
5. **JS**：`renderMessage` 改为统一卡片流渲染（取消左右头像）
6. **JS**：新增 `renderQuickSkills()` 渲染常用方案快捷入口
7. **JS**：`renderEmptyState` 中集成常用方案卡片
8. **JS**：`simulateAI` 中默认推荐的 Skill 卡片改为上下堆叠样式
9. **JS**：调整 `startWorkflow` 中的 Stepper 展示位置
