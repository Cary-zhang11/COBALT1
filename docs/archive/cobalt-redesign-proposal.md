# COBALT 界面重设计方案

## 一、设计系统

### 视觉方向
- **风格**: Flat Design —— 2D 极简、干净线条、无多余装饰、以排版为核心的专业 SaaS 气质
- **主题**: 亮色（Light），从现有的暗色全面转为清爽明亮的浅色基调
- **理念**: 减少视觉噪音，让聊天内容和 AI 产出成为绝对焦点

## 二、现有界面问题诊断

### 当前布局
- 暗色主题，信息密度偏低，视觉层级不清晰
- 侧边栏 290px 过宽，且导航与历史项目混排
- 聊天区消息气泡占据较宽（65%），大量留白不对称
- 工作流步骤使用列表式，缺少可视化进度感
-  emoji 作为图标，缺乏专业感
- Skill 市场、工作流、产出管理等面板内容单薄，交互感弱
- 没有明显的"新建项目"视觉引导

### 核心痛点
1. **内容对比度不足** —— 暗色下次级信息（时间戳、标签）难以区分主次
2. **缺少进度可视化** —— 工作流状态只能靠文字和颜色推断
3. **产出物展示简陋** —— 只有代码块 + 按钮，缺乏下载/预览的卡片质感
4. **缺少空状态设计** —— 新用户首次进入时引导不足

## 三、重设计方案

### 3.1 布局重构

```
┌─────────────────────────────────────────────────────────┐
│  Sidebar (260px)         │  Main Area                   │
│  ┌──────────────────────┐ │  ┌───────────────────────┐  │
│  │  Logo + New Btn      │ │  │  Top Bar              │  │
│  ├──────────────────────┤ │  ├───────────────────────┤  │
│  │  Nav Section         │ │  │                       │  │
│  │  • 问答助手          │ │  │  ┌──────────────────┐ │  │
│  │  • Skill 市场        │ │  │  │  Message Area    │ │  │
│  │  • 工作流监控        │ │  │  │                  │ │  │
│  │  • 产出管理          │ │  │  │  (chat / panel)  │ │  │
│  ├──────────────────────┤ │  │  └──────────────────┘ │  │
│  │  Project List        │ │  │                       │  │
│  │  ┌────┐ 项目名称     │ │  │  ┌──────────────────┐ │  │
│  │  ●   │ 状态指示     │ │  │  │  Input Area      │ │  │
│  │  ●   │ ...          │ │  │  └──────────────────┘ │  │
│  └──────────────────────┘ │  └───────────────────────┘  │
│                           │                              │
│  ┌──────────────────────┐ │                              │
│  │  User Profile        │ │                              │
│  └──────────────────────┘ │                              │
└─────────────────────────────────────────────────────────┘
```

**关键改动:**
1. 侧边栏宽度从 290px → 260px，更紧凑
2. Logo 区 + "新建项目" 按钮做成一个突出的行动区，视觉强化
3. 导航区与项目列表用分割线明确分隔
4. 用户头像放在底部，不再喧宾夺主

### 3.2 各区域详细设计

#### A. 侧边栏 (Sidebar)

| 元素 | 设计 |
|------|------|
| Logo | 文字 Logo "COBALT" + 简洁的六边形 SVG 图标，不再使用 emoji |
| 新建按钮 | 蓝色实心按钮，hover 时有轻微上移阴影，文字 "+ 新建项目" |
| 导航项 | 左侧 3px 竖线指示 active，圆角 8px，hover 背景变浅灰，图标用 Lucide SVG |
| 项目列表 | 圆点状态指示（running = 黄色动画，completed = 绿色，idle = 灰色），hover 显示操作按钮 |
| 用户区 | 简洁头像 + 姓名 + 角色 |

#### B. 顶部栏 (Top Bar)

- 标题 + 状态指示器组合，左侧对齐
- 状态用「彩色圆点 + 文字」紧凑展示
- 右上角可增加全局搜索框（后续扩展）

#### C. 聊天区域 (Chat View)

**消息气泡改动:**
- AI 消息：左侧头像 + 圆角卡片（左上 4px，其余 16px），背景 `#F1F5F9`，边框 `#E2E8F0`
- 用户消息：右侧，背景 `#EFF6FF`（accent 浅色），边框 `#BFDBFE`
- 最大宽度从 65% → 70%，更充分利用空间
- 头像改为 SVG 图标（AI = 机器人图标，用户 = 用户图标）

**Skill 卡片改动:**
- 横排卡片 → 改为更具可点击感的按钮或卡片组
- 左侧图标区域用蓝底白图标
- hover 时边框变蓝，整体微升

**工作流步骤改动:**
- 垂直列表 → **横向步骤条 (Stepper)**
- done = 绿色对勾图标 + 实线连接
- active = 蓝色脉冲圆点 + 加粗文字 + 当前高亮背景
- pending = 灰色空心圆
- 步骤条放在消息顶部，一眼看清进度

**确认弹窗改动:**
- 浅黄色背景 `#FFFBEB`，边框 `#FDE68A`
- 选项按钮做成类似标签页/标签组的样式
- 自定义输入框 + 确认按钮紧凑排列

**产出卡片改动:**
- 左侧加上文件类型图标（Markdown、Excel、PDF）
- 卡片标题 + 预览 + 操作按钮组（下载、复制、分享）
- 预览区域用代码编辑器风格（Monaco 风格浅色主题），圆角 8px

#### D. 输入区域 (Input Area)

- 底部固定，背景白色，上边框 `#E2E8F0`
- 输入框改为圆角矩形（不是大圆角），占位符文字用 `#94A3B8`
- 发送按钮改为蓝色实心圆角按钮（非圆形），文案 "发送"
- 附件按钮左侧，hover 显示工具提示

#### E. 面板视图 (Panel Views)

**Skill 市场:**
- 网格布局（2 列），每行 2 张卡片
- 卡片包含：图标区 + 名称 + 描述 + Token 用量 + 支持格式标签
- hover 时整体微升 + 蓝色边框

**工作流监控:**
- 垂直时间线布局（类似 GitHub timeline）
- 左侧时间线 + 右侧步骤详情卡片
- 每个步骤显示：状态图标 + 名称 + 时间 + 结果摘要

**产出管理:**
- 列表视图，每项一行
- 左侧文件图标 + 标题 + 日期 + Skill 标签
- 右侧操作按钮组（查看、下载、删除）
- 空状态：提示 "暂无产出，请先创建项目"

### 3.3 交互规范

| 场景 | 交互 |
|------|------|
| Hover 导航项 | 背景变浅灰，150ms ease |
| Hover Skill 卡片 | 上移 2px + 蓝色边框 + 阴影增强，200ms ease |
| 消息发送 | 用户消息滑入（右→左），AI 消息打字机效果 |
| 工作流步骤切换 | 当前步骤卡片高亮，连接线动画填充 |
| 文件上传 | 拖拽区域高亮（蓝色虚线边框），上传中进度指示 |
| 删除项目 | 项目行缩小 + 淡出，200ms |

### 3.4 空状态设计

| 场景 | 设计 |
|------|------|
| 新项目无消息 | 居中空状态插画（SVG）+ 引导文字 "描述你的需求或上传文档，AI 将为你处理" + 快捷操作按钮 |
| Skill 市场 | 网格展示所有可用 Skills，无空状态（始终有内容） |
| 工作流空闲 | 提示 "暂无运行中的工作流，从问答助手开始一个项目吧" + 跳转按钮 |
| 产出为空 | 空状态 + 提示文字 |
