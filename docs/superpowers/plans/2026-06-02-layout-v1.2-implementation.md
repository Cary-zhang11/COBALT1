# COBALT 用例生成布局 v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改配色、Sidebar、生成/执行主流程的前提下，将 `app/usecase-gen` 相关页面布局对齐 `docs/layout-spacing-preview.html` 建议模式 v1.2（宽度、单滚动、右栏单壳、Step3 评价与输出文件、看板用户评价、用例编辑壳层、日志页）。

**Tech Stack:** Next.js 14 App Router, React 18, Tailwind CSS, Prisma, TanStack Query, Recharts, Vitest, Testing Library

**验收对照：** 在浏览器打开 `docs/layout-spacing-preview.html`，切换到「建议 v1.2」，逐 Tab 与实现页面对照。不改：`login`/`register`、独立 `tasks` 页、Sidebar、弹窗、生成 execute 路由逻辑。

- [ ] **Step 2: 实现**

```ts
export function avgUserRating(ratings: number[]): number {
  if (ratings.length === 0) return 0;
  const sum = ratings.reduce((a, b) => a + b, 0);
  return Math.round((sum / ratings.length) * 10) / 10;
}

export function ratingDistribution(ratings: number[]) {
  const counts = [1, 2, 3, 4, 5].map((stars) => ({
    stars,
    count: ratings.filter((r) => r === stars).length,
  }));
  return counts;
}

export type FeedbackRow = {
  taskId: string;
  rating: number;
  comment: string | null;
  createdAt: Date;
};

export function latestFeedbackByTaskId(rows: FeedbackRow[]) {
  const map = new Map<string, FeedbackRow>();
  for (const row of rows) {
    const prev = map.get(row.taskId);
    if (!prev || row.createdAt > prev.createdAt) map.set(row.taskId, row);
  }
  return map;
}
```
