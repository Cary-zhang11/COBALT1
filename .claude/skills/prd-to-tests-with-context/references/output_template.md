# 输出文档模板

## 输出位置与命名规则

### 输出路径

沿用原用例文档所在目录：

```
{原用例目录}/{需求名称}_测试用例_完善版.md
```

- 如果原文件名为 `卖车页面改版_测试用例.md`
- 完善版文件名为 `卖车页面改版_测试用例_完善版.md`
- 输出到同一目录

## 来源标注规则

### 标注类型与位置

- `【需求变更补充】`：因新老需求差异新增 → 条件+动作行尾。例：`未勾选协议，点击提交按钮【需求变更补充】`
- `【历史用例补充】`：历史用例有、新用例遗漏 → 条件+动作行尾。例：`输入超长手机号（12位），点击发送验证码【历史用例补充】`
- `【历史Bug补充】`：基于历史 Bug 的回归验证 → 条件+动作行尾。例：`未填写手机号，点击提交按钮【历史Bug补充】`
- `【维度覆盖补充】`：系统性维度遗漏补充 → 条件+动作行尾。例：`输入边界值金额 99999.99，提交订单【维度覆盖补充】`
- `【历史复用】`：历史用例完全适用、未修改 → 条件+动作行尾（可选）。例：`查看头图区域【历史复用】`
- `【历史复用-已适配】`：历史用例场景适用、内容已更新 → 条件+动作行尾。例：`查看头图区域（新文案）【历史复用-已适配】`

### 标注优先级

多个标注共存时顺序：`【来源类型】→【历史复用/已适配】→【自动化:是】→【图片:xxx】`

### 废弃用例记录

历史用例中标记为废弃的，不在主文档中输出，仅在「历史资料分析摘要」中记录：

```markdown
### 3. 用例复用统计
...
- 应废弃：3 条
  - tc-old-045：推荐车源展示（模块已删除）
  - tc-old-067：旧版协议弹层（交互已改版）
  - tc-old-089：pvareaid=429 跳转（参数已变更）
```

## 完整性自检清单（完善版）

在原自检清单基础上，新增以下检查项：

### 补充用例检查
- [ ] 补充用例编号与原用例无重复
- [ ] 补充用例编号连续（或与原编号体系兼容）
- [ ] 所有补充用例都有来源标注（6种之一）
- [ ] 回归验证用例的预期结果包含"正确行为"验证
- [ ] 回归验证用例的预期结果包含"不出现历史Bug"验证

### 历史资料分析检查
- [ ] 变更分析清单已输出（如有老需求）
- [ ] 用例复用统计已输出（如有历史用例）
- [ ] Bug 回归统计已输出（如有 Bug 记录）
- [ ] 未提及功能已判断并记入待澄清或标注已删除

### 文档一致性检查
- [ ] 冒烟清单包含所有补充用例中的 P0/P1
- [ ] 回归测试清单包含所有 Bug 回归用例
- [ ] 历史资料分析摘要中的统计数字与实际用例数量一致
